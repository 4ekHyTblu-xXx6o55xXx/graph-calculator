## Архитектура первого модуля

Первый модуль представляет собой **автономное математическое вычислительное ядро и табулятор функций** с поддержкой символьной визуализации в терминале:

```
[Входная строка формулы]
           │
           ▼
     ┌───────────┐
     │ Tokenizer │  (разбиение на лексемы: числа, операторы, скобки, идентификаторы)
     └─────┬─────┘
           │ Tokens
           ▼
     ┌───────────┐
     │  Parser   │  (алгоритм Shunting-Yard, построение RPN, валидация скобок)
     └─────┬─────┘
           │ Expression (RPN)
           ▼
     ┌───────────┐
     │ Evaluator │  (стековое вычисление, функции 1 и 2 переменных, проверка Domain)
     └─────┬─────┘
           │ Числовые значения
           ▼
     ┌───────────┐
     │ Tabulator │  (дискретизация интервала [x_min, x_max] и двумерной сетки Grid2D)
     └─────┬─────┘
           │ Массив Point2D / Grid2D
           ▼
┌───────────────────────┐
│ PlotWindow / CLI      │  (ASCII-отрисовка кривых и карты высот 2D-функции)
└───────────────────────┘
```

### Поддерживаемые возможности первого модуля:
- **Арифметика:** `+`, `-`, `*`, `/`, `^` (возведение в степень), `%` (остаток), унарный минус/плюс.
- **Константы:** `pi` ($\pi \approx 3.14159265$), `e` ($e \approx 2.71828182$).
- **Функции 1 переменной:** `sin`, `cos`, `tan`, `cot`, `asin`, `acos`, `atan`, `sqrt`, `cbrt`, `abs`, `ln`, `log10`, `log2`, `exp`, `floor`, `ceil`.
- **Функции 2 переменных:** `min`, `max`, `pow`, `hypot`, `atan2`.
- **Обработка ошибок и разрывов:**
  - Деление на 0 (`5 / 0`).
  - Отрицательное под корнем (`sqrt(-1)`).
  - Логарифм неположительного числа (`ln(0)`, `ln(-5)`).
  - Тангенс/котангенс в точках разрыва.
  - Точки разрыва отмечаются на графике символом `!` без сбоя процесса табуляции.

## Быстрый старт на локальной машине

### 1. Запуск тестов (зелёный конвейер)
- **Windows:**
  ```cmd
  test.bat
  ```
  или:
  ```cmd
  python -m unittest discover -s tests -p "test_*.py" -v
  ```
- **Linux / macOS:**
  ```bash
  chmod +x ./test.sh
  ./test.sh
  ```

### 2. Запуск проверки сборки
- **Windows:**
  ```cmd
  build.bat
  ```
- **Linux / macOS:**
  ```bash
  chmod +x ./build.sh
  ./build.sh
  ```

### 3. Запуск калькулятора и построение графиков
- **Интерактивный режим:**
  ```cmd
  python -m src.cli
  ```
- **Построение графика функции 1 переменной в консоли:**
  ```cmd
  python -m src.cli --expr "sin(x)" --xmin -3.14 --xmax 3.14 --plot
  python -m src.cli --expr "x^3 - 3*x" --xmin -2.5 --xmax 2.5 --plot
  python -m src.cli --expr "1 / x" --xmin -2 --xmax 2 --plot
  ```
- **Построение карты высот функции 2 переменных:**
  ```cmd
  python -m src.cli --expr "x^2 + y^2" --2d --xmin -2 --xmax 2 --ymin -2 --ymax 2 --plot
  python -m src.cli --expr "sin(x) * cos(y)" --2d --xmin -3.14 --xmax 3.14 --ymin -3.14 --ymax 3.14 --plot
  ```

## Воспроизводимая сборка в Docker (на чистой машине)

По требованиям задания («работает у меня — не аргумент, аргумент — Dockerfile»):

```bash
# 1. Сборка контейнера
docker build -t graph-calculator .

# 2. Запуск проверки сборки
docker run --rm graph-calculator

# 3. Запуск тестов в чистом контейнере
docker run --rm graph-calculator ./test.sh

# 4. Запуск приложения в контейнере
docker run --rm graph-calculator python3 -m src.cli --expr "sin(x)" --plot
```

## GitLab CI/CD Конвейер

Файл `.gitlab-ci.yml` содержит две обязательные стадии:
1. `build`: компиляция байт-кода модулей и проверка синтаксиса (`./build.sh`).
2. `test`: прогон полного набора модульных тестов (`./test.sh`).

При каждом push или merge request конвейер автоматически запускает сборку и тесты. Пуш со сломанной сборкой или упавшим тестом блокирует конвейер и виден всей команде.
